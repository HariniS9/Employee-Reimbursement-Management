# Employee Reimbursement Management System

Spring Boot based reimbursement management application.

## Features

- Create Reimbursements
- Approval/Rejection Workflow
- Auto Approval Logic
- Audit Logging
- Status Filtering
- Amount-based Search
- H2 Database
- Unit Tests

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven
- JUnit 5
- Mockito
